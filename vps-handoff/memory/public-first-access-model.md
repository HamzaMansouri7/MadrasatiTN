Owner decided (2026-10-02, verbal): Madrasati TN is a free community site. All browsing/consuming features (library, docs bank, summaries, solve, discovery) must work WITHOUT login. Login required ONLY for authoring/social actions: studio (editor/generate), follow teacher, comment, ask question/request doc.

Consequence: parent space duplicates library → merge/collapse it; no separate gated parent workspace. Parent account optional, only for the gated actions above.

**Why:** community-good mission; zero-friction access drives adoption (same logic as public /solve and /summarize).
**How to apply:** when touching routes/guards, don't add auth walls to read paths; gate only write/social actions at the action level (modal prompt), not the page level. See [[product-vision-resource-hub]], [[teachers-are-authors]].
