1. **Configurer les paramètres**: choose the output language (see the language shown on each message).
2. **Configurer le chat → Personnalisé**: paste the text of [00-GLOBAL-CHAT-SETTINGS.md](00-GLOBAL-CHAT-SETTINGS.md), save.

Next try = same name with v2, v3. Never keep a generic name.
